## 원고에 넣기 전에 확인이 필요한 점

1. 측정 방법: burst는 N개를 동시에 보냈는지, 1차와 2차 사이 간격은 얼마였는지, 클라이언트는 어디에서 실행했는지(서울 EC2인지)
2. 이미지: "1GB Agent 이미지"의 압축 크기와 구성(언어, 프레임워크). 원고의 1gb 이미지는 cold start p75가 13.41초였고 원문은 15.44초입니다. 이미지가 달라서 생긴 차이로 적었습니다
3. 풀이 10으로 돌아오기까지 걸린 유휴 시간
4. 엔드포인트 분산(rr1, rr2) 결과: 원문에는 엔드포인트 3개 구성 화면만 있고 분산 결과 수치는 없습니다. 원고는 2026-11-13 서울에서 따로 측정한 값을 씁니다(엔드포인트 1개 빠른 세션 10/30, 3개 30/30, `results-seoul/endpoint_pool-0410.json`). 원문에 분산 측정 결과가 있으면 공유 부탁드립니다
5. 바이라인과 저자 소개에 들어갈 영문 이름, 한글 이름, 직함, 소개 문단
