## verification.md 끝에 추가 — 측정 리전 (2026-11-13 확정)

```markdown
## 측정 리전 (2026-11-13 확정)

- 직접 측정한 결과로 쓰는 원고는 서울 리전(ap-northeast-2) 중심으로만 작성한다. 다른 리전에서 측정한 값(같은 실험의 다른 리전 라운드, 대조군 포함)은 본문, 표, 그림, 캡션에 넣지 않는다
- 서울 리전에서 아직 제공되지 않는 기능이라 다른 리전에서 측정해야 했다면, 원고를 쓰기 전에 사용자에게 먼저 확인한다
- AWS 발표문이나 공식 블로그가 공개한 수치는 리전을 밝히지 않은 비교 기준으로 인용할 수 있다. 이때 표 캡션에 "발표 수치의 측정 리전과 표본 수는 발표문에 밝혀져 있지 않습니다"처럼 출처의 전제를 적는다
- 단가 표는 서울 리전 가격표(AWS 가격표 API의 ap-northeast-2 offer 파일)에서 확인한 값으로 쓰고, 캡션에 게시일을 적는다
```

## 이번 세션에서 확인한 사항 (규칙 후보, 사용자 확정 전)

아래는 작업 중 확인한 사실이고 사용자가 규칙으로 확정하지 않았으므로 references에 넣지 않았습니다. 확정하면 위와 같은 형식으로 옮깁니다.

- 발표문이 "기본값 변경"이나 "동작 변경"을 알리면 본문에 쓰기 전에 API로 재현해 확인한다(2026-11-13 AgentCore Runtime V2 기본값 발표와 실제 API 동작이 달랐다)
- docs.aws.amazon.com 외에 aws.amazon.com의 What's New, 블로그, 요금 페이지도 `/ko/` 경로로 리디렉션되므로, 한국어 tech 블로그의 참고 자료에는 `/ko/` URL을 사용하고 제목은 그 페이지의 실제 제목(9월 GA 발표문은 한국어 제목)을 쓴다
- AWS 서비스 아키텍처 그림을 aws-diagram으로 그린 뒤 render_diagrams.py로 렌더하려면, diagram_lib의 Canvas와 같은 `@font-face` 선언으로 SVG를 감싼 HTML을 만들어야 `fonts: True` 검사가 의미를 가진다
- 자동 오버플로 검사는 캔버스 경계만 보므로 존 테두리를 넘는 라벨은 잡지 못한다. PNG를 눈으로 볼 때 존 오른쪽 끝의 수치 라벨을 따로 확인한다
